# Expense Tracker

A command-line app to track personal expenses, built with Python.

## Features
- Add, view, edit, and delete expenses
- Search by category
- Show total
- Data saved in a SQLite database

## Project structure
- main.py: runs the menu
- expenses.py: expense logic and input validation
- storage.py: SQLite database functions
- test_expenses.py: tests

## How to run
python main.py

## How to run tests
python test_expenses.py
